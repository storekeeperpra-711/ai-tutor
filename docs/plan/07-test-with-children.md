# Phase 7: testing with real children

Phase 7 is done when **a 5-year-old can finish a counting lesson without reading**, and **a Grade 9 student finds the home screen clear and not childish**. Only real children can tell us that. This checklist is for you (or a teacher) to run with a few children.

## Before you start

1. Install the newest dev app (GitHub → Actions → newest CI run on main → **ai-tutor-debug-apks** at the bottom).
2. Turn the phone's volume up. Make sure the phone has a text-to-speech voice (Settings → Accessibility → Text-to-speech). Urdu is best; English works too.
3. Optional but much better: record Mithu's lines first. Home → **Record Mithu's voice** (at the bottom of the home screen in the dev app). Record the Count the mangoes lines in Urdu, tap the share icon, and attach the files in the project chat.
4. Add a learner for each child (Nursery, Grade 4, Grade 7 and Grade 9 or 10, for example), with a parent's agreement.

Don't help the child unless they are stuck for a long time. Watch, and write down what happened.

## A. Nursery or Prep child (age 4 to 6): Count the mangoes

Give the phone to the child after picking their picture. Say only "Play with Mithu".

| Check | Yes / No | Notes |
|---|---|---|
| Mithu greets them by name, and they notice he's talking. | | |
| They find the big Play button without help. | | |
| They understand "tap a mango" from Mithu's voice alone. | | |
| They put the right number of mangoes in the basket on most steps. | | |
| They find out how to take a mango out of the basket again. | | |
| They understand the tick button means "I'm done". | | |
| On the picture cards (number, dots, fingers) they choose by looking, not guessing. | | |
| When wrong, Mithu's curious face does not upset them, and they try again. | | |

| They could do it without anyone reading anything to them. | | |

If they got stuck on the same kind of step several times, the app may show a written "take a break" message. Note if that happened: young children can't read it.
