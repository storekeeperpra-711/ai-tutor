# AI Tutor

An AI tutor app for low-income students in Punjab, Pakistan (nursery to FSc), built with Flutter, Firebase and Claude.

- **Spec:** [docs/master-prompt.md](docs/master-prompt.md) is the master prompt and source of truth for the project.
- **Plan:** [docs/plan/](docs/plan/) holds the analysis and the task list for each phase.

Work happens one phase at a time; the next phase starts only after the current one meets its acceptance criteria and is confirmed.
